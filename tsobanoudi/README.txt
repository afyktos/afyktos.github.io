TSOBANOUDI — WEBSITE DELIVERY

Open index.html with VS Code Live Server (recommended) or any local web server.

Included:
- Responsive homepage for desktop / tablet / mobile
- Optimized autoplay hero video (hero-web.mp4)
- Projects archive with filters and image lightbox
- Furniture archive with image lightbox
- About and Contact pages
- Mobile full-screen navigation
- Phone, email and Google Maps actions
- Contact form fallback that opens a pre-filled email
- Lazy-loaded gallery images and reduced-motion fallback

Production handoff notes:
- Connect the contact form to the client's preferred form/email backend.
- Connect Projects / Furniture to a CMS so the owner can add entries without editing code.
- Add the client's confirmed Instagram/Facebook URLs.
- Replace/confirm project titles and locations with the client's final naming.
- Compress/resize any new images before upload.
